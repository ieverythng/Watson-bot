# Opinions

Preferences and beliefs, each with confidence and evidence.

## Format

- `opinion`: short statement
- `confidence`: `0.00-1.00`
- `updated`: YYYY-MM-DD
- `evidence`: list of source files

## Entries

- `opinion`: OM architecture should use hybrid lanes and reflective compression.
  - `confidence`: 0.90
  - `updated`: 2026-03-12
  - `evidence`:
    - `reports/research/memory-architecture-review-2026-02-24.md`
    - `reports/recipes/01-om-loop.md`
