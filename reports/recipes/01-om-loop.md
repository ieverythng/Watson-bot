# Recipe 01 - OM Loop (Observer/Reflector)

## Purpose
Run a disciplined Observational Memory loop with auditable outputs.

## Triggers
- After meaningful tool runs
- After completed work blocks
- After config/repo changes
- Every ~10-20 conversational turns
- At session end or milestone transitions

## Observer Steps
1. Capture current context and work block outcome.
2. Append compact observation to `OBSERVATIONS.md`.
3. Log the block in `memory/YYYY-MM-DD.md`.
4. Include risk/uncertainty and next step.

## Reflector Steps
1. Periodically review recent observations and daily memory logs.
2. Condense patterns into `REFLECTIONS.md`.
3. Promote only durable, evidence-backed items to `MEMORY.md`.
4. Keep summaries compact; avoid chatty bloat.

## Output Standard
Each loop should preserve:
- what changed
- why it matters
- confidence/risk
- evidence
- actionable next step
