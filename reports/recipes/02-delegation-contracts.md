# Recipe 02 - Delegation Contracts

## Purpose
Ensure non-trivial delegated tasks are scoped, auditable, and safe.

## Contract Template
- Objective
- Scope
- Allowed tools
- Allowed folders
- Deliverables
- Acceptance checks
- Rollback plan
- Escalation triggers
- Audit destination

## Procedure
1. Draft contract before delegation.
2. Validate scope boundaries and acceptance checks.
3. Execute under contract constraints.
4. Run review against acceptance checks.
5. Log outcome + evidence to memory/observations.

## Policy
Use delegation only when complexity justifies it.
Default to one active delegate.
Do not spawn swarms without explicit need.
