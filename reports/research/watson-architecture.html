Per-Session Model Switching (/model)

🔄 Dynamic Model Selection in Discord

Hermes Gateway supports the /model slash command — switch models per channel without changing global config:

# Switch this session to gpt-5.5 via chatgpt-plus
/model gpt-5.5 --provider chatgpt-plus

# Switch and persist globally (writes to config.yaml)
/model gpt-5.5 --provider chatgpt-plus --global
