Executive Summary

Kickbacks.ai is an ad marketplace that replaces the "thinking..." spinner text in AI coding assistants (Claude Code, Codex) with clickable sponsored ads. Users receive 50% of ad revenue — credited per impression (≥5 second view) and per click (clicks worth 50× an impression). The platform is very early stage (~163 stars, ~128 installs), making this a first-mover opportunity but also carrying significant startup risk.

Realistic monthly revenue per active user: $50–$100 at current bid rates ($25/1k impressions), reduced by known bugs that cause 20-40% impression loss.

Known Bugs & Flakiness (Root Cause Analysis)

🐛 CRITICAL: Kill Wedge Deadlock (#48)

Symptom: Extension stops showing ads permanently until manual Developer: Reload Window. This is the PRIMARY cause of "flaky" behavior.

Root cause: Campaign-scoped kill confirmed → checkKill keeps polling the dead campaignId → serving gate blocks rotation → infinite loop. The extension re-confirms its own kill every 30 seconds forever.

Workaround: Developer: Reload Window in VS Code resets the state. Or deploy the watchdog script (see Phase 2).

Impact: Can lose 100% of impressions for hours if not caught. Estimated to cause ~20-30% impression loss across all users.

🐛 Codex Adapter "target not found" (#55)

Symptom: Diagnostics show hasAd=true, codexCompatible=true, but ads never render. Dashboard shows $0.00.

Root cause: boot.cycle.done {"ok":false,"reason":"target not found"} — the Codex panel DOM structure changed and Kickbacks can't find the injection point.

Impact: Codex VS Code surface is effectively broken for affected versions. Focus on Claude Code surfaces until fixed.

🐛 Ads Display but No Credit (#52)

Symptom: Ads render in spinner but impressions are not credited to account. Multiple users affected.

Root cause: Unknown — possibly view-tracking timer failing or impression telemetry not reaching backend.

Impact: Unpredictable revenue loss. Monitor closely via kickbacks.ai/me ledger.

🐛 Codex CLI Wrapper Breaks on macOS (#53)

Symptom: CRLF shebang + ESM exec of renamed entry point breaks Codex CLI on macOS.

Impact: Not applicable to your WSL/Linux environment. Documented for completeness.

Risk Assessment

Platform Existential Risk

128 installs, 163 GitHub stars. This is a micro-startup. If advertiser demand doesn't grow or the maintainer loses interest, the platform could shut down at any time. All revenue from this source should be treated as bonus income, not reliable income.

Bug-Induced Revenue Loss

The kill wedge deadlock alone can cause 100% impression loss for hours. Without the watchdog, expect 20-40% of potential impressions lost to bugs. The Codex adapter being broken eliminates one surface entirely.

ToS Violation Risk

Kickbacks.ai explicitly warns against artificial impression generation. Automated scripts that simulate coding work solely to generate impressions risk permanent bans. Only generate impressions as a natural byproduct of real coding work.
