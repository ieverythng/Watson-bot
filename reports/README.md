# Reports Directory

This folder stores generated analysis, diagnostics, and one-off audit outputs.

## Structure

- `reports/openclaw/` → OpenClaw health checks, baseline tests, security summaries
- (future) `reports/research/` → research summaries and literature scans
- (future) `reports/projects/` → project-specific diagnostics and review snapshots

## Naming

Use date-stamped filenames when useful:
- `topic-YYYY-MM-DD.md`

This keeps generated files organized and easy to find during refactors.
