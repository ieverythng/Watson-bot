## VRAM-Aware Orchestrator (orchestrate-session.sh)

Built adaptive model routing system — `scripts/game-server/orchestrate-session.sh`:

**Three model tiers, switched based on VRAM + game state:**
- **Remote tier:** GPT-5.4-mini via gateway (zero local VRAM cost) — default during gaming
- **Lightweight tier:** LFM2-8B on port 8081/4001 — when VRAM headroom ≥ 4GB allows it
- **Full tier:** 27B Qwen3.6 via Lazarus — restored after game exits

**Flow:** Kill full stack → switch to remote (GPT-5.4-mini) → launch game → monitor + adaptive switching → game exits → kill lightweight → Lazarus revives 27B

**Key design decisions:**
- GPT-5.4-mini stays operational during gameplay (remote = no VRAM cost)
- Lightweight model only loads when VRAM headroom allows (deterministic threshold: 4GB free)
- Full restore via Lazarus after game exits
- Mina process name: `MinaTheHollower` (non-Steam, direct exe launch)
