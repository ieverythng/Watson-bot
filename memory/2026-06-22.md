## Remote Gaming Server Project

### Session Start
Juan requested a remote gaming architecture: turn his PC into a game streaming server for Zsani to play remotely from her laptop/iPad, with Watson orchestrating everything. Priority game: Equinox: Homecoming (Steam).

### Research Completed
Dispatched 3 parallel research subagents (all background=true):
1. **Platform comparison** — Moonlight+Sunshine wins over Steam Link, Parsec (no iPad), GameStream (dead)
2. **Resource analysis** — Equinox needs 4-8GB VRAM + 8-12GB RAM; llama.cpp 27B needs 11-13GB VRAM. Cannot run simultaneously on 16GB/16GB hardware. Solution: auto-pause Watson before game, resume after.
3. **Sunshine automation** — Sessions are client-driven (Moonlight connects → Sunshine launches app). No "start stream via API" — but can automate app launch and use prep commands.

### Key Findings
- **Platform:** Moonlight + Sunshine is the clear winner (best latency, iPad support, controller passthrough, open source)
- **iPad controllers:** Bluetooth controller paired to iPad → Moonlight captures input → relays through stream → Sunshine presents as virtual Xbox controller on Windows host
- **Network:** UDP ports 47998-48000, 48010. Tailscale VPN recommended over port forwarding for NAT traversal
- **NVENC settings:** H.264/HEVC, P1/P2 preset, CBR, 15-25 Mbps for 1080p60
